AIMM icons and motion

Design preview, build base 2026-11-23.18. Not the app. Hover, press, Tab through and click everything. Inter loads from this folder, the same self-hosted file the spec asks for.

The set

One family: 24 grid, round caps and joins, currentColor, no fills, no boxes. Each icon at 16, 20 and 24 pixels, with stroke 2.0, 1.75 and 1.6 so all three read as the same thin line. Base: Lucide (ISC licence), inlined as a sprite.
