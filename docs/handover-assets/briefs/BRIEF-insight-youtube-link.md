## Worker (worker/src/index.js, aimm-proxy)
1. POST /kb/add-youtube {url}: browser path (ALLOWED_ORIGINS check, the existing rate-limit pattern, small body). Parse the video id from youtube.com/watch, youtu.be, shorts, and share links with ?si= extras. Reject non-YouTube URLs with a plain message. If the video is already in the library (repo index or user index), return {ok:true, already:true, ...} without calling Apify.
2. Call Apify, join segments, clean and chunk exactly like scripts/ingest_yt.py (about 500 words, flush on sentence end). channel = Apify channelName.
3. Reuse the existing /kb/upsert logic (refactor into a shared function; keep /kb/upsert behaviour and its ingest-key gate unchanged) to embed into Vectorize with video_id, chunk, title, channel, text.
4. Store the full transcript and metadata in AIMM_KV: key yt-user:<video_id> and a list key yt-user:index (id, title, channel, url, added, chunks). 
5. Return {ok, video_id, title, channel, chunks, words, already, transcript_for_summary} where transcript_for_summary is the first ~12000 characters.
6. GET /kb/user-videos (index) and GET /kb/transcript?id= (full text) for the app, same origin rules.
7. Plain error messages: no captions, Apify failed, quota used up. Never expose the token or upstream error bodies containing it.
