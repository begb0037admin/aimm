A — speaker / stop
  • Icons 18px, stroke 1.8, hit area 28x28 invisible
  • Gap 20px between hit areas (icon-to-icon 30px visual)
  • Row margin-top 10px; margin-left 11px so the star glyph lines up with the bubble text edge (16px padding)
  • One button changes in place: i-volume grey, then i-stop teal
  • Labels: "Read aloud" / "Stop reading" (title + aria-label; aria-pressed on the toggle)
  • Favourite: "Add to favourites" / "Remove from favourites", solid teal when saved. Copy: "Copy reply" (swap to i-check for 1.5s, label "Copied")
B — play / stop
  • Same sizes, hit area, gap, margins, labels as A
  • i-play grey, then i-stop teal in the same slot
  • Matches the Fix Queue / Stem mix play language; reads as a transporter
  • Play also means "play audio" elsewhere (stem playback), so it is less clearly "Hope speaks"
C — speaker + stop
  • Same sizes, hit area, gap, margins, labels as A
  • Speaker turns teal while reading; separate stop icon appears after it (gap 20px)
  • Row grows by one icon while reading, so Copy shifts right 48px: a visible jump
  • Two controls for one job; speaker looks tappable but does nothing
Recommendation: Option A. One icon in one fixed slot, so nothing moves and the row never grows. The speaker says "Hope talks" at a glance; the teal stop square says "stop" while it reads. It stays plain line icons, no boxes, and teal means active, matching the rest of AIMM. B is a close second if you want it to match the Fix Queue play button exactly. C is not recommended because Copy jumps sideways.
