# Sonnox Oxford Inflator — mixing, loudness, and distortion reference for Logic Pro

Source: https://store-8pfrvbtcba.mybigcommerce.com/content/plugins/user-guides/Oxford_Inflator_User_Guide.html
Authority: Sonnox Oxford Inflator User Guide. Paraphrased operational reference for Hope; not a verbatim copy. Treat starting settings as starting points, not universal presets.

## Chunk 1

Sonnox Oxford Inflator: what it does and how to use it in Logic Pro. Inflator can increase perceived loudness and average signal density while largely preserving the original dynamic envelope rather than using conventional time-constant compression. It can also generate extra harmonic character and a valve-like, rounded sound. This is useful on mix buses, masters, and individual tracks or instruments for controlled density and saturation. Logic Pro can host the Audio Units (AU) version if installed and authorised. Confirm that Sonnox Oxford Inflator is in Kevin's installed plugin library before prescribing it.

Basic full-range loudness setup, adapted from Sonnox: start with CLIP 0dB ON, BAND SPLIT OFF (direct mode), CURVE 0 (centre), EFFECT 100%. Increase INPUT carefully so peaks occasionally reach the plugin's 0dB input indicator, rather than pushing blindly. Monitor INPUT/OUTPUT meters and adjust OUTPUT for the intended peak ceiling. Compare processed and bypassed sound at matched loudness; beware of mistaking louder for better. The plugin's loudness gain does not replace a final true-peak check or distribution-specific limiting.

## Chunk 2

Sonnox Oxford Inflator CURVE controls the character rather than acting as ordinary EQ. At -50, perceived loudness change is relatively subtle, with harmonic enrichment and a sense of tightened or more forward transients; a useful experiment on drums, percussion, and acoustic guitar. Curve 0 is the balanced starting point: more fullness, warmth, harmonic detail, and rounded peaks, while keeping the apparent dynamic contrast. Positive CURVE settings progressively add density, loudness and "in your face" weight; +50 is the most assertive character, but can trade away some dynamic precision.

For most mixing and natural analogue-style overdrive, use direct full-band mode (BAND SPLIT OFF). Band Split divides audio into low, mid, and high bands and can sometimes help a frequency-heavy programme by reducing intermodulation, but it can create new output peaks or harsher clipping. Do not enable Band Split as an automatic default.

## Chunk 3

Sonnox Oxford Inflator deliberate distortion / saturation technique: set EFFECT to 100% initially, BAND SPLIT OFF, CURVE 0. Raise INPUT gradually to overdrive the Inflator, and reduce OUTPUT enough to avoid unintended output clipping. Listen to the actual distortion character and adjust CURVE only as needed. Compare CLIP 0dB ON versus OFF because they create materially different overdrive textures. CLIP 0dB ON constrains the processing to the normal digital maximum; OFF allows an internal overdrive region of up to roughly +6dBr before hard clipping. This is internal operating range, not permission to clip subsequent plugin stages or the final output.

For natural, valve-like warmth, Sonnox favours CURVE 0 and direct mode. For more aggressive audible distortion, experiment with INPUT and CLIP 0dB, including the order of plugins before Inflator. On a vocal, bass, 808, drum bus or sample in Logic Pro, use the effect deliberately and monitor peaks and tone; do not impose identical gain settings on different sources.

## Chunk 4

Oxford Inflator on Logic Pro's Stereo Out / mix bus: Sonnox describes a mixing-as-you-go starting approach with BAND SPLIT OFF, CURVE 0, CLIP 0dB OFF, INPUT around +6 dB, and OUTPUT at 0 dB. This creates a virtual operating reference around -6dBr with room for short transient overshoots inside Inflator. It is a specific suggested mix-bus workflow, NOT a mastering target or safe gain prescription for every source. If using it, audit the upstream and downstream peak behaviour in Logic Pro and adjust to programme material.

Important difference in practice: for deliberate distortion, reduce OUTPUT as you increase INPUT to avoid output overload; for the manual's reference-level mixing workflow, OUTPUT starts at 0 dB and the overall level must be monitored. If peaks exceed acceptable limits, lower signal levels or choose less overdrive. In any chain involving compressor -> Oxford Inflator -> limiter, avoid unintended clipping between stages and check final true peak and loudness requirements. Confirm plugin availability from the live AIMM library before Hope gives concrete settings.
