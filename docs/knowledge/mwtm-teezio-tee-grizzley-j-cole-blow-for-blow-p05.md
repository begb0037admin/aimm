## Chunk 1

Okay, so running to the mix bus up top, Fresh Air, which I tend to do this a lot when I get to a point in the record where everything is sitting good, everything's already running through the master bus, I'm loud, and I'm just feeling like the vocals and the record sounds like it's just got a hand in front of the mouth, like it's just covered up too much. So I'm adding 11% of some top. 11% on Fresh is pretty aggressive. Let's see what that sounds like on Jay's part. So it just cuts through just a little bit more, a little bit more top. After that, I have the insert, which is the VT5 happening here. This tends to move depending on where I need it. Occasionally it'll be on the Neve return. If I'm hitting it too hard coming off of the Neve, I'm able to move this around in case I needed to put it in a different place. So the VT5 is there on an insert. After that, I'm hitting it with this BX, which I use this on every mix, and we'll just follow out each of these frequencies that I'm taking out. So we'll start here. Absolutely horrible frequencies here. What's this? So that's like 3.15, super sharp to the ears. That's the resonant 2K, and then we're doing a 500 here. Yeah, so what I'm doing is I'm sort of trying to find these frequencies and push them back a bit in the hopes of allowing other things that aren't resonant to sort of shine through and get rid of these things, all in the hopes of being able to play it louder and louder without frequencies resonating and hurting your ears. After that, I'm hitting it with the V-clip. This is a clipper that I love to use. Let's see how much clip we're getting on this. The clipper is just being used to reduce dynamics without using compression. A lot of the complaints that I would get when you're like dealing with massive 808s is that 808 tends to swallow up and push the compressor and make the whole record sound like it's sort of breathing. So with the clippers, I'm actually able to gain loudness, reduce dynamics, and not have that breathing feeling. After the V-clip, it goes right into this orange clip, which I'm doing about 1 dB of clipping on it with a really hard knee. This is all reducing, reducing so that I can get louder and louder and not have too much limiting happening at the end. The Kirchhoff EQ is, I would consider this like my main master EQ where I'm able to sort of dial in certain little parts. Let's go through these really quick and see what I'm cutting. So that's one. And then the last one. These are all frequencies that I don't really care for, that they need to sort of be subdued and taken out of the mix to allow the other things to shine through more.

## Chunk 2

After that, I'm hitting it with this Shadow Hills. What'll happen with this compressor here, especially with an 808 this big, if you start to really get compression, it'll really start to push it down and the vocals will start to sound like they're being swallowed by the 808. And then when the 808 comes out, it'll sound like the vocals get louder. So with this, I've sort of started to actually phase this out and I put the Orion on there. What ended up happening is all these records with giant 808s, when it would hit this and just even get the slightest amount of compression, the 808 would start to swallow up the compressor and then the vocals would change and I'd have to automate the vocals a little bit. After that, God Particle. And last plug-in, these are my two limiters at the end. So I basically run these serially into each other. So I have the God Particle running into this Oxford. Between the God Particle limiting and what's happening on the Oxford, I'm probably getting 1.2, 1.3 dBs of total limiting happening at the very end, which is sort of what I'm aiming for. I want this mix to be loud, but I want it to be dynamic. I don't want there to be a ton of limiting because especially, again, with records like this with big 808s, that tends to create big issues with how the record feels and breathes. And then I'm hitting the curve, the enhanced curve. So there's a pretty, I love using this enhanced curve. I put it on every record. It's usually between like 30 and 40 and it just pushes everything forward. It just gets it in your face. And like, you don't really notice until you A-B it, but I'll A-B it right now. That for me is like, boom, mix is done after that. It's super loud. We got two approvals fairly close.
