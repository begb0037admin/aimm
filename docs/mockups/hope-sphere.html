Implementation Notes

Replaces the floating mic button

Same draggable float position, same localStorage position persistence. The sphere canvas sits inside the existing float container — no structural HTML changes beyond swapping the mic SVG for a canvas element.

~150 particles arranged mathematically on a sphere surface. Concentric latitude/longitude rings give the dense equatorial band visible in the reference image. Canvas 2D only — no Three.js or WebGL.

Speaking state hooks into the Web Audio API analyser node already wired to the ElevenLabs audio output (same infrastructure as the spectral analyser on the Mix Check tab). Sphere radius and particle scatter respond to RMS amplitude in real time.

Colour temperature lerps smoothly between states: calm = teal (#06b6d4) → engaged = purple (#a78bfa) → emphatic = white-hot (#f0f9ff).
