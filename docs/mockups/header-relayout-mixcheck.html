What moved

1
Tab strip — full width + taller. The Mix-Check-only left indent (margin-left: calc(--mc-rail-w + --gutter)) is removed, so the strip spans the whole content column, flush left with the wordmark and flush right with the banner / transport / specs grid, exactly like every other tab. Vertical padding 6px → 11px, label 9px → 10.5px. With the extra room and no equal-width clamp the 9 full labels fit with no ellipsis. It stays a block child of .app-col — no wrapper change.
2
Genre / Target / Settings — down to the title row. The .header-actions cluster leaves the top-right of .header-top and sits on the right of the Mix Check title row (.mc-head), vertically centred against the 24px title. Same three controls, same ids/handlers, same blue-lit-when-selected styling.
3
Drop / browse WAV — into the transport bar. The loader split-button leaves .mc-head. Loaded state: it is a compact “Load WAV ▾” button at the end of the transport control row (after the timecodes); the ▾ menu still carries browse / live input / capture tab; the eject/clear affordance stays. Empty state: the transport card is always shown now and its body becomes the drop target — dashed panel, “Drop a WAV here”, the full-size Drop / browse WAV ▾ button, and the “browse file · live input · capture tab” caption. Transport controls, timecodes and #mcWave stay inside #refDzLoaded and only appear once a file loads. The loader is reachable in both states.
4
Vacated top-right. Nothing needs to fill it. On Mix Check, .header-top becomes a slim brand-only bar — net effect is more vertical breathing room above the now-prominent full-width tab strip, which matches Kevin’s stated layout preference. (If something is wanted there later, the dormant #panelTitleBar persona/status strip is the natural revive — Markey’s node, out of scope here.)

5 — Scope decision: Mix-Check-scoped This is a Mix-Check-only relayout. .header-actions is shared shell chrome (Genre and Target drive plugin starring and the master target on Workbench / Library; Settings is a global shortcut), so it must not be deleted from the other tabs. Recommended mechanism: a small relocation shim — the same pattern AIMM already uses to move #refDzLoaded into #mcTransport and .aichat-layout between the Conversation panel and the Hope rail. When #eq (Mix Check) becomes active the .header-actions node is moved into .mc-head; when any other tab activates it is moved back into .header-top. All ids and handlers travel with the node.

Implication for the other 8 tabs: none — they still show Genre ▾  Target ▾  Settings at the top-right of .header-top exactly as today. Only Mix Check moves the cluster down to its title row and leaves its own .header-top as a brand bar.

Fallback if the shim is judged too risky to add to shared chrome during the R3 post-ship round: make it a global change — the cluster moves to the right-hand end of the (now full-width) tab-strip row on every tab. No JS, but it changes all 8 other tabs and it sits one row higher than the “level with the Mix Check title” placement Kevin asked for.
