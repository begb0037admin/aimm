DESIGN MOCKUP — NOT LIVE CODE — Jules, 2026-09-05 What this shows: a redesigned, expanded Platform Loudness Comparison table for Mix Check, shown in realistic context alongside the live Audio Specs / Spectral Balance / Fix Queue cards. Not merged, no build change — pure mockup for Kevin's review before any implementation.
  • Why this exists: Kevin pointed at loudnesspenalty.com and said its all-platforms-at-once table "is more useful" than a single-platform picker. AIMM already has a half-built version of exactly this idea — a .ref-pt-table "Platform Loudness Comparison" table currently sitting dormant (data-dormant="mixcheck-r5-legacy", main index.html ~line 2924) with 4 rows (Trap/Club, Spotify/YouTube, Apple Music, SoundCloud) plus a separate True Peak Ceilings table. This mockup builds directly on that table's visual language (same row grid, same pass/warn/fail colour convention as .ref-pt-actual/.ref-pt-status) rather than inventing something new — just expanded to the fuller platform list and redesigned to read as one glanceable "penalty" report the way loudnesspenalty.com's does.
  • Platform list expanded from 4 → 8: YouTube, Spotify, Tidal, Apple Music, Amazon Music, Pandora, Deezer, SoundCloud — the same 7 loudnesspenalty.com shows, plus SoundCloud kept in (relevant to Kevin's trap/hip-hop focus, and was already in AIMM's dormant table).
  • Design call — a visible dB delta, not just pass/fail: loudnesspenalty.com's whole value is the number ("this platform will turn you down 2.5 dB"), not a binary check. This mockup shows Target, Your Mix (measured), and a signed Δ dB column, then a status chip derived from that delta (±1 dB = on target / 1–4 dB = moderate turn-down / >4 dB = heavy turn-down) — so the useful number is always visible, and the chip gives an at-a-glance read for anyone who doesn't want to parse dB values.
  • Illustrative dataset: a competitively loud trap/club master reading −9.0 LUFS integrated (True Peak −0.6 dBTP) — deliberately hot, so the table demonstrates the actual "penalty" pattern loudnesspenalty.com is known for: heavy turn-down on every normalising streaming platform, but no penalty on SoundCloud (loud-upload convention, no enforced normalisation). Numbers are realistic published platform targets, not placeholders.
  • Placement — two options shown via the toggle below, Jules' recommendation is Option A: see the placement note under the stage for the reasoning.
  • Everything outside the new card (tab strip, Audio Specs, Spectral Balance, Fix Queue, Hope rail) is simplified context dressing only, styled to the same tokens as the live app — not a pixel-exact reproduction, and not itself part of this design proposal.
